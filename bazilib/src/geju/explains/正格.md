# 正格 · 成格条件

条件按 `bazilib/src/geju/categories/` 下 detector 的**实际代码**逐条录出，非泛论。
标 `[岁运]` 的条件在大运/流年层另判：主局缺可被补齐（Trigger），主局有可被冲破（Break）。

术语：**透** = 出现在年/月/时天干（日主自身不计）；**藏** = 出现在地支藏干；
**紧贴** = 两个十神所在柱相邻（下标差 1）；**本气** = 地支藏干首位。

---

## 月令定格的通用前提

除建禄格、阳刃格、魁罡格外，其余 8 个正格都先过 `monthGeFormed()`：

1. 月支若同时是日主的**刃位**，则所有正格让位给阳刃格，一律不成立。
2. 满足以下任一即算"月令为某十神"：
   - 月令**本气**即该十神；或
   - 月令**中气/余气**藏该十神，**且该十神透干**。

---

## 建禄格

1. 月支 = 日主之**禄位**（十二长生「临官」位）。
2. 月令**不被冲**——四柱中非月支的任一支与月支六冲即破。`[岁运]` 大运/流年含月支之冲同样破。
3. **有出口**：官杀 / 财 / 食伤 三者之一**透干且通根**（透 + 同类十神藏于地支）。
   `[岁运]` 主局缺出口时，岁运透官杀/财/食伤且局中有对应藏干可补成。
4. **身不过旺**：比劫计数 + 印计数 < 6。

## 阳刃格

1. 月支 = 日主之**刃位**（十二长生「帝旺」位）。
2. **必有官杀制刃**：官杀透干。`[岁运]` 主局无官杀时，岁运透官杀可补成。
3. **不得破格**：正官透 + 七杀不透 + 伤官透 + 无印透 → 破。
   `[岁运]` 岁运参与后同样判此条，且印的救护也计岁运。

## 正官格

1. 月令正官（本气，或藏而透干）。
2. 日主**非**「身极弱」「近从弱」。
3. **不混七杀**：七杀不透。`[岁运]` 岁运透七杀 → Break。
4. **无伤官紧贴克官**：不得出现「伤官透 + 伤官与正官紧贴 + 无印透」。
   `[岁运]` 岁运透伤官且主局与岁运皆无印 → Break。

## 七杀格

1. 月令七杀（本气，或藏而透干）。
2. 日主**非**「身极弱」「近从弱」。
3. **正官不得透**——除非正官被日干**合去**（日干的五合对象恰为其正官，且该正官在月干或时干）。
   `[岁运]` 岁运透正官且未合去 → Break。
4. **必有制或化**：食神（透或藏）**或**印（透或藏）至少居其一。
   `[岁运]` 岁运补食神/印可补成。

## 食神格

1. 月令食神（本气，或藏而透干）。
2. 日主**非**「身极弱」「近从弱」。
3. **无枭夺食**：不得出现「偏印透 + 偏印与食神紧贴 + 无财透」。
   `[岁运]` 岁运透偏印且主局与岁运皆无财 → Break。

## 伤官格

1. 月令伤官（本气，或藏而透干）。
2. 日主**非**「身极弱」「近从弱」。
3. **无正官透**（伤官见官为祸）。`[岁运]` 岁运透正官 → Break。
4. **不混食神**：食神不透。`[岁运]` 岁运透食神 → Break。

> 注：金水伤官喜见官的流派例外**未实现**，本 detector 一律禁正官。

## 正财格

1. 月令正财（本气，或藏而透干）。
2. 日主**非**「身极弱」「近从弱」。
3. **无比劫夺财**：不得出现「劫财或比肩与正财紧贴 + 无官杀透」。
   `[岁运]` 岁运透比劫且主局与岁运皆无官杀 → Break。

## 偏财格

1. 月令偏财（本气，或藏而透干）。
2. 身弱要求较正财**宽松**：仅当「身极弱/近从弱」**且**比劫计数 + 印计数 = 0 时才否决。
3. **无比劫夺财**：不得出现「劫财或比肩与偏财紧贴 + 无食伤透 + 无官杀透」
   （食伤化或官杀制皆可解）。`[岁运]` 岁运透比劫且两侧皆无食伤/官杀 → Break。

## 正印格

1. 月令正印（本气，或藏而透干）。
2. **身印不失衡**：若「身极旺」**且**无财透**且**无食伤透 → 否决（闷气机）。
3. **无财破印**：不得出现「正财或偏财与正印紧贴 + 无比劫透」。
   `[岁运]` 岁运透财且主局与岁运皆无比劫 → Break。

## 偏印格

1. 月令偏印（本气，或藏而透干）。
2. 日主**非**「身极旺」。
3. **偏印不过重**：偏印透干位数 + 偏印透干柱数 ≤ 2，超过即否决。
4. **无枭夺食**：不得出现「偏印透 + 偏印与食神紧贴 + 无财透」。
   `[岁运]` 岁运透偏印致总量超 2 → Break；岁运透偏印且两侧无财 → Break。

## 魁罡格

不走月令定格，条件全部在日柱与全局：

1. 日柱为**魁罡日**之一：庚辰、庚戌、壬辰、戊戌。
2. **身旺**（`strength.shenWang`，即量化总分 ≥ 30）。
3. **无忌神五行透干**：庚辰/庚戌/壬辰 忌**火**透，戊戌 忌**水**透。
4. **日支不被辰戌冲**：日支为辰则其余三柱不得见戌；日支为戌则不得见辰。

> 魁罡格不经 `emitGeju`，无岁运 Trigger/Break 分支，命中即为原局成格。
