# 专旺格 · 成格条件

`isZhuanWangGe` 是**派发器**：依次尝试 曲直 / 炎上 / 稼穑 / 从革 / 润下，命中即把
`name` 改写为「专旺格」，原子格名收进 `note`。所以 UI 上显示的是「专旺格」，
实际命中的是下列 **5 个独立格局**之一。

五格共用 `checkZhuanWang(ctx, 目标五行, maxCaiTou)`，差异只在 **日主五行** 与 **财透上限**。

标 `[岁运]` 的条件可被大运/流年补齐或冲破。

---

## 共用判据（五格全部必须满足）

1. **日主与月令同气**：日主五行 = 目标五行，**且**得令（`strength.deLing`，即月令修正为正值）。
   静态条件，岁运不可补。
2. **地支成局** `[岁运]`
   - 非土：地支齐 **三合**（木亥卯未 / 火寅午戌 / 金巳酉丑 / 水申子辰）
     **或** **三会**（木寅卯辰 / 火巳午未 / 金申酉戌 / 水亥子丑）。
   - 土：辰戌丑未**四库占位 ≥ 3**（按位数计，重复亦算；四库不重复齐见为「四库齐」）。
3. **天干一气** `[岁运]`：天干中「目标五行 + 印星五行」计数 ≥ 2（含日主本身）。
4. **无克本气** `[岁运]`：正官、七杀**均不透**，且官杀居地支本气的柱数 < 2
   （中气/余气藏可容）。
5. **食伤微泄**：食伤透干位数 + 食伤居地支本气柱数 ≤ 1。
   多透多根即为泄过，不成格。`[岁运]` 岁运加量超阈 → Break。
6. **财透控量**：财透位数 ≤ `maxCaiTou`。除稼穑为 1 外，其余四格均为 **0**。

---

## 曲直格

- 日主五行 = **木**（甲/乙）
- 其余全部走共用判据，`maxCaiTou = 0`

## 炎上格

- 日主五行 = **火**（丙/丁）
- 其余全部走共用判据，`maxCaiTou = 0`

## 稼穑格

土格在共用判据外**额外收紧**：

1. 日主五行 = **土**（戊/己）
2. 月支必须是 **辰、戌、丑、未**之一（其余四格无此限制）
3. **天干土数下限**随库的层次浮动：
   - 四柱中**不重复**的库支 ≥ 3（层次足）→ 天干土 ≥ **2**
   - 不重复库支 < 3（重复库，层次薄）→ 天干土 ≥ **3**

   `[岁运]` 岁运天干土可计入。
4. `maxCaiTou = 1`（土格放宽一位财透）
5. 另有稼穑专属收紧：财透 + 财居地支本气的总位数 **< 2**
6. **升格「稼穑毓秀」**：局中或岁运有金点缀（天干金 + 地支本气金 > 0）→ note 标注

> 注：稼穑的印为火，与「土一气」性质相反，故共用判据第 3 条的印星在此**不计入**。

## 从革格

- 日主五行 = **金**（庚/辛）
- 其余全部走共用判据，`maxCaiTou = 0`

## 润下格

- 日主五行 = **水**（壬/癸）
- 其余全部走共用判据，`maxCaiTou = 0`

---

## 岁运裁断

- 主局齐 1–6 条 + 岁运不破 → **显**（原局成格）
- 主局齐 + 岁运透官杀/食伤/超限财 → **显 + Break**
- 主局缺第 2 或第 3 条 + 岁运地支补三合三会 / 天干补同气 → **隐 + Trigger**
- 主局已有第 4、5 条的破气（官杀透、食伤多透） → 已破，**不补**，直接不挂格
