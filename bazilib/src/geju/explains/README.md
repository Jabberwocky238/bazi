## 岁运语义

标 `[岁运]` 的条件会在「主局」与「主局 + 大运/流年」各判一次，两次结果的组合
决定挂格方式（见 `_emit.ts`）：

| 主局 | 加岁运 | 结果 |
|---|---|---|
| 成 | 成 / 无岁运 | **显** —— 原局成格 |
| 成 | 不成 | **显 + Break** —— 原局成格但被岁运破 |
| 不成 | 成 | **隐 + Trigger** —— 原局未成，岁运补齐 |
| 不成 | 不成 | 不挂格 |

「显/隐」由 `deriveVisibility` 从岁运段派生：仅岁运特定且无 `DefaultTrigger`
和 `Trigger` 撑起时为**隐**，其余为**显**。

  → 见 [从格.md](./从格.md)。
