# 五行格（五行象法 / 两气成象）· 成格条件

同一文件内的数格**互斥**，由 `judgeFromCounts` 一次裁断出唯一结果，
再由各 detector 用 `pick(ctx, 目标名)` 取自己那一个。所以同一命盘
不会同时命中「水火既济」与「水火相战」。

## 计数口径（全篇通用）

| 记法 | 含义 |
|---|---|
| 天干X | 四柱**天干**中该五行的柱数（含日主） |
| 地支X | 四柱**地支本气**（藏干首位）为该五行的柱数 |
| X总数 | 天干X + 地支X |
| 本中气含X | 任一柱地支的**本气或中气**含该五行（`rootExt`） |

`[岁运]` 各格均为「主局判一次、主局+岁运判一次」，两次结果不同即 Trigger 或 Break。

---

## 水火类（互斥，优先级：日照江河 > 水火既济 > 水火相战）

### 日照江河

1. 日干为 **丙**
2. 天干水 > 0
3. 火有根：地支火 > 0 **或** 天干火 > 1
4. 水旺：地支水 ≥ 2 **或** 天干水 ≥ 2
5. 天干土 < 2（无厚土塞流）

### 水火既济

先过「水火双透有根 + 势均」的公共门槛：

1. 水双现：天干水 > 0 **且** 地支水 > 0
2. 火双现：天干火 > 0 **且** 地支火 > 0
3. 势均：|水总数 − 火总数| ≤ 2

再加本格专属：

4. **天干木 > 0**（有木通关）
5. **天干金 < 2**（无重金破木）

### 水火相战

公共门槛同上（1–3 条），再加：

4. **天干木 = 0**（无木通关）
5. **天干土 = 0**（无土调和）

---

## 木火类

### 木火通明

1. 日主五行为 **木**
2. **非**「火过旺而木根虚」——即不同时满足 `火多 + 地支木 ≤ 1 + 全局无水`
   （该组合会先被判为木火相煎）
3. 水**未成根**：不同时满足 天干水 > 0 且 地支水 > 0
4. 天干火 > 0 **且** 地支火 > 0（火透坐本气根）
5. **本中气含木**（木有根）
6. 天干金 < 2（无重金）

### 木火相煎

1. 日主五行为 **木**
2. 火多：天干火 ≥ 2 **或** 地支火 ≥ 2
3. 木根虚：地支木 ≤ 1
4. **全局无水**：天干水 = 0 **且** 地支水 = 0

### 木多火塞

1. 日主五行为 **火**
2. 地支木 ≥ 3
3. 火弱：地支火 = 0 **或** 地支火 < 2
4. 无金疏通：天干金 = 0 **或** 天干金 < 2

---

## 土金类

### 土金毓秀

1. 日主五行为 **土**
2. 天干金 > 0 **且** 地支金 > 0（金透通根）
3. 地支土 > 0（土有根）
4. 天干木 = 0（无木克土）
5. 天干火 < 2（无重火克金）

### 土重金埋

1. 日主五行为 **金**
2. 土厚：地支土 ≥ 3 **或** 天干土 ≥ 2
3. 地支金 = 0（金虚无根）
4. **木未成根**：不同时满足 天干木 > 0 且 地支木 > 0
5. **水未成根**：不同时满足 天干水 > 0 且 地支水 > 0

---

## 火金类（三格均要求日主五行为 **金**）

### 金火铸印

1. 地支金 > 0（金有根）
2. 天干火 > 0 **且** 地支火 > 0（火透坐根）
3. 天干火 < 3（火不过旺）

### 火多金熔

1. 火重：天干火 ≥ 2 **或** 地支火 ≥ 2
2. 地支金 = 0（金无根）
3. 天干金 < 2
4. **水未成根**（不同时满足 天干水 > 0 且 地支水 > 0）
5. **土未成根**（不同时满足 天干土 > 0 且 地支土 > 0）

### 火旺金衰

1. 天干火 ≥ 2
2. 地支金 = 0（金无根）
3. 天干土 = 0（无土通关）

---

## 火土类（两格均要求 天干火 > 0 且 天干土 > 0）

### 火土夹带

1. 地支火 > 0 **且** 地支土 > 0（火土相连有根）
2. **有水**：天干水 > 0 **或** 地支水 > 0

### 火炎土燥

1. 火重：天干火 ≥ 2 **或** 地支火 ≥ 2
2. **全局无水**：天干水 = 0 **且** 地支水 = 0

---

## 水木类

### 水木清华

1. 日主五行为 **水** 或 **木**
2. 天干水 > 0 **且** 天干木 > 0
3. 天干金 = 0（无金克木）
4. 地支土 < 2（无重土塞水）
5. **火未坐根**：不同时满足 天干火 > 0 且 本中气含火
6. 木总数 > 0 **且** 水总数 ≤ 木总数 × 2（水木比例合宜）

### 水多木漂

1. 日主五行为 **木**
2. 水盛：天干水 ≥ 2 **或** 地支水 ≥ 3
3. 地支木 = 0（木无根）
4. 天干土 = 0（无土制水）
5. 天干火 = 0（无火泄木）

### 水冷木寒

1. 日主五行为 **木**
2. **月令季节为冬**
3. 水旺：天干水 ≥ 2 **或** 地支水 ≥ 2
4. 天干火 = 0（无火调候）
5. 天干土 = 0（无土制水）

---

## 金水类

### 金白水清

1. 日主五行为 **金**
2. **月令季节为秋或冬**
3. 天干水 > 0 **且** 地支水 > 0
4. 地支金 > 0
5. 天干土 = 0
6. 天干火 = 0

> 月支为申或酉时，note 额外标注「月令秋金当令」。

### 金寒水冷

1. **月令季节为冬**
2. 日主五行为 **金** 或 **水**
3. 天干金 > 0 **且** 天干水 > 0
4. 天干火 = 0（火缺调候）

---

## 木土类

### 木疏厚土

1. 日主五行为 **土**
2. 地支土 ≥ 2（土厚）
3. 天干土 ≥ 1
4. 天干木 > 0 **且** 天干木 ≤ 2（木透而不过量）
5. **本中气含木**（木有根能疏）
6. 天干金 < 2（无重金克木）

`[岁运]` 岁运透木 → Trigger；岁运透重金 → Break。

---

## 金木类

### 斧斤伐木

1. 日主五行为 **木**
2. **木有根**（`rootWx('木')`，透+藏任一处含木）
3. 天干金 > 0（金透才成象）
4. 金总数 ≤ 3（金不过量）
5. 水总数 < 3
6. 土总数 < 3

`[岁运]` 岁运透金 → Trigger；岁运透重水/重土 → Break。
