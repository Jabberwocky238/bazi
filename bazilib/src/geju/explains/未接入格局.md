# 未接入的格局 · 成格条件

`categories/` 下另有 **31 个文件**，各含一个格局，但**未接入 `geju/index.ts` 的
`DETECTORS` 表**——排盘时不会被调用，也不会出现在结果里。

它们依赖 commit `8ff72ee` 删除的 `../snapshot` 全局读取 API
（`readBazi()` / `readShishen()` / `readStrength()` / `readExtras()`，
无参数、从全局快照取数），全部带 `@ts-nocheck`，不参与类型检查与编译。

下列条件按各文件**现有代码**录出，供将来改写为 `GejuContext` 形式时对照。
注意旧 API 的 `shishen.tou(x)` 返回**裸布尔**，而现行 `ctx.ss.tou(x)` 返回
`[boolean, number[]]` 元组——迁移时这是主要的改写点。

术语与岁运语义见 [README.md](./README.md)。

## 官杀类（4）

### 财官印全

1. 日主**非**「身极弱」「近从弱」
2. **财透且通根**（正财或偏财，透 + 同类藏）
3. **官杀透且通根**（正官或七杀）
4. **印透且通根**（正印或偏印）
5. 正官与七杀**不同时透**（不混杂）
6. 无「伤官透 + 伤官与正官紧贴」
7. 无「比肩/劫财 与 正财/偏财 紧贴」

`[岁运]` 岁运补另一方官杀致混杂 / 透伤官 / 透比劫 → Break。

### 官印相生

1. **正官透**
2. **正官藏**（通根）
3. **印透**（正印或偏印）
4. **印藏**（正印或偏印）
5. **正官与印紧贴**
6. 日主**非**「身极弱」「近从弱」
7. 七杀**不透**（不混杂）
8. 无「财与印紧贴」（正财/偏财 × 正印/偏印 四种组合皆不可）
9. 无「伤官透 + 伤官与正官紧贴 + 无印透」

`[岁运]` 岁运透七杀 / 透财 / 透伤官（且两侧无印）→ Break。

### 杀印相生

1. **印紧贴日主**：月干或时干为正印或偏印
2. 日主**非**「身极弱」「近从弱」
3. **互斥**：不得为「阴日主 + 伤官透 + 七杀透 + 伤官七杀紧贴」（让位伤官合杀）
4. **七杀显**：月令本气为七杀 **或** 七杀透 **或** 七杀藏
   - 若七杀是**透**的，还须与正印或偏印紧贴
   - 若七杀仅藏支或居月令本气，不要求紧贴
5. **印透且通根**
6. 正官**不透**
7. 无「财与印紧贴」

`[岁运]` 岁运透正官 / 透财 → Break；岁运补七杀或印 → Trigger。

### 官杀混杂

1. 局中**有正官**（透或藏）
2. 局中**有七杀**（透或藏）
3. 正官或七杀**至少一方透干**

note 按情形分三档：双透为「显混杂」，一透一藏为「隐混杂」，
仅靠岁运引入为「岁运引混杂」。

`[岁运]` 岁运补齐缺失的一方 → Trigger。

## 食伤类（10）

### 食神制杀

1. 日主**非**「身极弱」「近从弱」
2. **食神与七杀紧贴**（静态严判，不满足直接否决）
3. **七杀显**：月令本气为七杀 **或**（七杀透 + 七杀藏）
4. **食神透且通根**
5. **食杀两停**：食神计数 × 2 ≥ 七杀计数 **且** 七杀计数 × 2 ≥ 食神计数，
   且七杀计数 > 0
6. 无「偏印透 + 偏印与食神紧贴 + 无财透」（无枭夺食）

`[岁运]` 岁运补七杀/食神 → Trigger；岁运透偏印且两侧无财 → Break。

### 伤官合杀

1. **阴日主**（乙/丁/己/辛/癸——伤官与七杀恰构成五合）
2. 若主局伤官与七杀**都透**，则二者必须**紧贴**，否则直接否决
3. **双透**：伤官透 + 七杀透
4. **无争合**：年/月/时天干中，伤官 ≤ 1 位、七杀 ≤ 1 位

`[岁运]` 一方主局透、另一方岁运透 → Trigger；岁运使任一方超过 1 位 → Break。

### 身杀两停

1. **身旺**（`strength.shenWang`）
2. **日主五行本中气有根**（`rootExt(dayWx)`）
3. **七杀透且通根**
4. **官杀计数 ≥ 3**
5. 正官**不透**（不混杂）

`[岁运]` 岁运透七杀补量 → Trigger；岁运透正官 → Break。

### 伤官佩印

1. **身弱**（`strength.shenRuo`）
2. **伤官显**：月令本气为伤官 **或**（伤官透 + 伤官藏），**且**伤官透
3. **印透且通根**
4. 无「财与印紧贴」
5. 正官**不透**

`[岁运]` 岁运补伤官/印 → Trigger；岁运透财 / 透正官 → Break。

### 伤官生财

1. 日主**非**「身极弱」「近从弱」
2. **伤官显**：伤官透 **或** 月令本气为伤官
3. **财显**：财透 **或** 正财/偏财藏
4. **印不碍**：无印透 **或**（印不与伤官紧贴 **且** 印不与财紧贴）
5. 无「正官透 + 伤官与正官紧贴」

`[岁运]` 岁运透印 → Break（近似判，不严判紧贴）；岁运透正官 → Break。

### 伤官见官

1. 日主五行**不为金**（金水伤官喜见官，故排除）
2. 伤官与正官**同现**（各自透或藏皆可）
3. 二者**至少一方透干**
4. **位置接近**：伤官所在柱与正官所在柱下标差 ≤ 1
5. **无救**：印**不透** **且** 财**不透**

`[岁运]` 岁运补齐缺失方或使之紧贴 → Trigger；岁运透印或财 → 有救，不成立。

> 这是本组唯一按「柱下标差 ≤ 1」而非 `adjacentTou` 判紧贴的，
> 且计入地支藏干位置（`posOfShishen` 同时扫天干十神与 `hideShishen`）。

### 食神生财

1. 日主**非**「身极弱」「近从弱」
2. **食神显**：食神透 **或** 月令本气为食神
3. **财显**：财透 **或** 正财/偏财藏
4. **印不碍**：无印透 **或**（印不与食神紧贴 **且** 印不与财紧贴）
5. 无「偏印透 + 偏印与食神紧贴 + 无财透」
6. 无「比肩/劫财 与 财紧贴 + 无官杀透」

`[岁运]` 岁运透印 / 偏印 / 比劫（各自无救时）→ Break。

### 食伤泄秀

1. **身旺**（`strength.shenWang`）
2. **食伤显**：（食神透+藏）**或**（伤官透+藏）**或** 月令本气为食神/伤官
3. **清而不杂**：食神与伤官**不同时透**
4. 无「偏印与食神/伤官紧贴 + 无财透」

`[岁运]` 岁运补食伤 → Trigger；岁运使食神伤官双透 → Break。

### 食伤混杂

1. **食神透 且 伤官透**
2. **无救**：印**不透** **且** 财**不透**

`[岁运]` 岁运补齐另一方致双透 → Trigger；岁运透印或财 → 有救，不成立。

### 枭神夺食

1. **不得为**「伤官居月令本气 且 伤官透」（该情形另属伤官格）
2. **偏印透**
3. 局中**有食神**（透或藏）
4. **无救**：财**不透** **且** 比劫**不透**
5. 若食神**透**，则偏印必须与食神**紧贴**；食神仅藏时不要求紧贴

`[岁运]` 岁运透偏印或补食神 → Trigger；岁运透财或比劫 → 有救，不成立。

## 羊刃 / 比劫 / 财类（6）

### 羊刃驾杀

1. **阳日主**
2. **刃位见于月支、日支或时支**（年支不算）
3. **七杀透**
4. **七杀藏**（通根）
5. **身旺**（`strength.shenWang`）
6. **印不过重**：年/月/时天干印 < 2 位 **且** 印居地支本气 < 2 柱
7. **食伤不过重**：同上口径 < 2

`[岁运]` 岁运透印或食伤 → Break。

### 羊刃劫财

1. **阳日主**
2. **月支 = 刃位**（严判月支，不含日/时支）
3. **劫财透**
4. **官杀不透**（无制）

`[岁运]` 岁运透官杀 → Break。

### 比劫重重

1. **量达标**（二选一）：
   - 比劫透干计数 ≥ 2；该计数 = 比肩透(0/1) + 劫财透(0/1) +
     「年月时天干中比劫类 > 1 位则再 +1」
   - **或** 比劫居地支本气 ≥ 3 柱
2. **官杀不透**（无制）

`[岁运]` 岁运补比劫达标 → Trigger；岁运透官杀 → Break。

### 劫财见财

1. **劫财透且通根**
2. **财透**
3. **比劫计数 > 财计数**
4. **官杀不透** **且** 食伤不透（无制无化）

`[岁运]` 岁运补劫财/财 → Trigger；岁运透官杀或食伤 → Break。

### 财多身弱

1. **身弱**（`strength.shenRuo`）
2. **财量达标**：财透 ≥ 2 位 **或** 财居地支本气 ≥ 2 柱

`[岁运]` 岁运补财达标 → Trigger；岁运透印或比劫 → Break（身得帮扶则不成立）。

### 以财破印

1. **印计数 ≥ 3**（印重为病）
2. **财透且通根**（正财或偏财）
3. **财与印紧贴**
4. **不得为**「身弱 且 比劫计数 = 0」
5. **有出口**：食伤透 **或** 官杀透 ← 此条即 `baseFormed`

`[岁运]` 主局无出口时，岁运透食伤或官杀 → Trigger。

## 特殊类（11）

### 禄马同乡

1. 存在某一柱，其**地支同时是**日主的**禄位**与**驿马**
   （驿马由年支或日支起算，`yimaFrom`）
2. 该地支**不被四柱中其他支六冲**
3. 日主**非**「身极弱」「近从弱」

`[岁运]` 岁运带该支之冲 → Break。

### 日德格

1. **日柱为日德**：甲寅、丙辰、戊辰、庚辰、壬戌
2. **叠见**：年/月/时柱中至少一柱的干支也在日德集合内
3. **日支不被冲**
4. 不得出现「七杀透 且 月干或时干为七杀」
5. **无忌魁罡**：按日柱查禁忌表（甲寅忌庚辰、丙辰忌壬辰、戊辰忌壬戌…），
   年/月/时柱不得出现对应干支

`[岁运]` 岁运出现禁忌魁罡干支 → Break。

### 日贵格

1. **日柱为日贵**：丁亥、丁酉、癸巳、癸卯
2. **日支不被冲**
3. **官杀透**

带合更牢固：日支的六合支（亥↔寅、酉↔辰、巳↔申、卯↔戌）出现在其他柱时，
note 标注「带合牢固」。

本格**不经 `emitGeju`**，自行装配岁运段：`DefaultTrigger` 恒为 true；
岁运带日支之**冲 / 害 / 合**任一 → `Conquer`（冲害标记，非 Break）。

### 三奇格

1. 天干含某组三奇**且顺序递增**（按柱位下标）：
   - 乙丙丁（人中三奇）
   - 甲戊庚（天上三奇）
   - 壬癸辛（地下三奇）
2. 顺序不对（下标非升序）→ 直接否决，不再试下一组

`[岁运]` 岁运地支冲三奇任一天干的**禄位** → Break。

### 三庚格

1. 日主五行**不为金**
2. 不得为「日主五行为木 **且** 身弱」
3. **天干庚 ≥ 3 位**

`[岁运]` 岁运天干补庚达 3 位 → Trigger。

### 天元一气

1. **四柱天干完全相同**

`[岁运]` 岁运天干出现克该五行者 → Break。

### 壬骑龙背

1. **日柱为壬辰**
2. 四柱**不见戌**（辰戌冲则破）
3. **助力至少居其一**：
   - 年/月/时天干另有壬
   - 年/月/时地支另有辰
   - 金透干或金有根
   - 木透干
4. **天干火 < 2 且 天干土 < 2**

`[岁运]` 岁运见戌 → Break；岁运补助力 → Trigger。

### 化气格

1. 日干与**月干或时干**构成五合：甲己化土 / 乙庚化金 / 丙辛化水 /
   丁壬化木 / 戊癸化火
2. **化干无根**：日主五行在局中无根（`rootWx(dayWx)` 为假）
3. **化神旺**：月令本气五行 = 化神五行 **或** 化神居地支本气 ≥ 2 柱
4. **日干不重出**：四柱中与日干相同的天干仅 1 位（即日干自己）

`[岁运]` 岁运透日主五行或日干本身 → Break（复根破化）。

### 两气成象

1. 全局（四柱天干 + 地支本气）**只见两种五行**
2. 二者为**相生**关系
3. **势均**：两方总数之差 ≤ 2

本格**不经 `emitGeju`**，命中即返回，无岁运分支。

### 五行齐全

1. 四柱天干与**全部地支藏干**（本/中/余气）合计，五行**木火土金水齐备**

本格**不经 `emitGeju`**，命中即返回，无岁运分支。

### 帝王命造

复合格，依赖其他 detector 的结果：

1. **不得为**「身弱 且 不得令」
2. **底盘**：命中 `财官印全` **或** `专旺格` 至少其一
3. **无破格**：不得命中 `官杀混杂`、`伤官见官`、`枭神夺食` 任一
4. 大运配合（`extras.daYunMeta`）决定岁运段：
   - 大运**顺行** 且 连续喜用 ≥ 3 步 → `Trigger`
   - 连续忌用 ≥ 3 步 **或** 大运逆行 → `Conquer`

本格**不经 `emitGeju`**，自行装配岁运段。
