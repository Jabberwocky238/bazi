# 从格 · 成格条件

`isCongGe` 是**派发器**：依次尝试 弃命从财 / 弃命从煞 / 弃命从势 / 从儿格，
命中即把 `name` 改写为「从格」，原子格名收进 `note`。实际命中的是下列
**4 个独立格局**之一。

> `从格.ts` 里另有 `isCongGuanGe`（从官格）、`isCongQiangGe`（从强格）、
> `isCongWangGe`（从旺格）三个函数，**未被派发器调用**，是不可达的死代码
> （20 万盘随机对拍从未出现）。故不在此列。

标 `[岁运]` 的条件可被大运/流年补齐或冲破。

---

## 共用判据 `checkCong`（从财 / 从煞 用；从势、从儿另有自己的守卫）

1. **地支不见比劫/印**：四柱全部藏干（本气/中气/余气）中，不得有任一为比劫或印。
   静态条件，任一藏即破。
2. **月令属目标类别**：`monthCat` = 目标（财 / 官杀）。
3. **地支主气支撑**：目标五行居地支本气的柱数 ≥ 1。
4. **天干不透比劫/印** `[岁运]`：主局严判；岁运透比劫或印 → 复根 Break。
5. **目标类别透干** `[岁运]`：主局缺时，岁运透目标可补成 Trigger。

---

## 弃命从财

共用判据（目标 = 财，目标五行 = 日主所克之五行）之外：

6. **财计数 ≥ 3**（透 + 藏合计）
7. **财计数 ≥ 食伤计数**

## 弃命从煞

共用判据（目标 = 官杀，目标五行 = 克日主之五行）之外：

6. **官杀计数 ≥ 5**
7. **官杀计数 ≥ 财计数**
8. **官杀计数 > 食伤计数**
9. **食伤不透**（食伤克官杀则不从）。`[岁运]` 岁运透食伤 → Break。

## 弃命从势

不走 `checkCong`，自带一套（依《滴天髓·从象》任铁樵注）：

1. **日主完全无根**：比劫不透、印不透，**且**四柱全部藏干中皆无比劫、无印
   （任一位置藏即破）。
2. **三党中 ≥ 2 种强势并立**：财 / 官杀 / 食伤，每一党需**透干且通根**
   （透 + 同类十神藏于地支）才算「强势」，满足者需 ≥ 2 党。
3. **顺流通关**：必须存在「食伤 + 财」或「财 + 官杀」至少一条相生链。
   仅「食伤 + 官杀」两党强势而无财居中，不成格。
4. `[岁运]` 岁运透比劫或印 → 复根 Break。

## 从儿格

不走 `checkCong`，自带一套（《滴天髓·从儿》「从儿不管身强弱，只要吾儿又遇儿」）：

1. **比劫不透**
2. **印不透**
3. **官杀不透**（「从儿最忌官杀，次忌印绶」）
4. **月令不属比劫、不属印**
5. **食伤五行居地支本气 ≥ 2 柱**
6. **食伤计数 ≥ 4**（透 + 藏合计）
7. **食伤计数 > 财计数**
8. **食伤透干** `[岁运]`：主局缺时岁运补透可 Trigger。
9. `[岁运]` 岁运透比劫 / 印 / 官杀 → Break。

---

## 与专旺格的互斥

二者理论互斥（专旺为身强一气，从格为身弱无根）。边界重叠时由 `detectGejuWith`
裁断：**只保留先命中者**，后者丢弃。DETECTORS 表中专旺格排在从格之前。
